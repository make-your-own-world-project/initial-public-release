# Bedeutung ändert sich mit der Zeit

![Frühere Beweise, spätere Bedeutungen und sich ändernde Interpretationen bleiben über die Zeit hinweg miteinander verbunden](../../assets/temporal-meaning-preserved-history.png)

## Die Karte befindet sich über dem Korpus

Der Korpus bewahrt Einlagen. Eine separate zeitliche Schicht erfasst Beziehungen, Interpretationen, Klassifizierungsversuche, Wichtigkeitsbeiträge und deren Geschichte. Diese Ebene kann sich kontinuierlich ändern, ohne die ursprünglichen Artefakte zu verändern.

Ein früherer Link wird nicht gelöscht, wenn eine spätere Interpretation besser ist. Die spätere Beobachtung kann sie bestätigen, einengen, widersprechen, neu einordnen oder ersetzen. Der frühere Link bleibt als die zu diesem Zeitpunkt verfügbare Ansicht gültig und erläutert möglicherweise den Weg zu späteren Arbeiten.

## Zeit ist kein einzelner Zeitstempel

Das System unterscheidet mindestens:

- wenn ein Artefakt vom Korpus beobachtet wurde;
- wann eine bestimmte Darstellung erfasst oder erstellt wurde;
- wann die reale Aktivität möglicherweise begonnen hat;
- wenn ein Ereignis eingetreten zu sein scheint;
- ob sich das Artefakt auf Vergangenheit, Gegenwart, Zukunft, gemischt, zeitlos oder unbekannt bezieht
  Zeit;
- wann eine Interpretation als gültig angesehen wurde;
- als diese Interpretation aufgezeichnet wurde;
- als eine spätere Beobachtung es verdrängte.

Ein kürzlich zugelassenes Dokument kann Arbeiten betreffen, die viel früher begonnen wurden. Eine aktuelle Notiz kann eine Erinnerung, eine Vorhersage, eine Sorge, eine Planung oder eine zeitlose Reflexion sein. Die Zulassung gilt niemals als Nachweis des Studienbeginns.

## Gründe sind Beobachtungen, keine dauerhaften Etiketten

Eine vernunftähnliche Beziehung zeichnet ihre Autorität und ihren epistemischen Status auf. Dabei kann es sich um eine direkte Quellenangabe, eine direkt beobachtete Struktur, einen von einem Spezialisten abgeleiteten Kandidaten, eine deterministische Projektion, eine unterstützte Schlussfolgerung, eine mögliche Assoziation, einen Widerspruch, eine Neuzuordnung oder eine Unbekannte handeln.

Strukturelle Hervorhebung, Modellvertrauen, Wiederholung, Zentralität und Zielgruppenanpassung können nützliche Dimensionen sein. Niemand wird stillschweigend in das umgewandelt, was einer Person am Herzen liegt.

## Die persönliche Bedeutungsmatrix

Die Personal Meaning Matrix ist eine anfragebezogene Sicht auf diese quellenbezogenen Beobachtungen. Es kann mehrere Dimensionen enthalten, ohne sie in eine universelle Wichtigkeitszahl zu zwingen. Zu den Kandidatendimensionen gehören:

- Aufmerksamkeits- und Aufwandsinvestition;
- Projekt- und Aktivitätsstruktur;
- Diskursprominenz und kausale Reichweite;
- Beweisstärke und Unsicherheit;
- Konflikt, Korrektur und Schutz vor offenen Fragen;
- äußere Zwänge und Umgebungsbedingungen;
- Werte, Identität, Einschätzung und beabsichtigte Ergebnisse, sofern nachgewiesen;
- Ausdrucksweise, Reflexion, Humor, Ironie oder künstlerische Gestaltung;
- Beständigkeit und Veränderung im Laufe der Zeit;
- Relevanz für einen deklarierten Empfänger und ein Produkt.

Die Matrix ist kein Persönlichkeitssimulator und beantwortet keine zeitlose Frage darüber, was eine Person sagen würde. Der Beobachterstatus ist zeitgebunden. Ein späterer Zustand kann sich von einem früheren unterscheiden und beide bleiben Teil der Karte.

## Rückwärtsentdeckung und Vorwärtsrekonstruktion

Beliebige Daten werden oft verständlicher, wenn die Durchquerung von einer späteren, kontextreichen Beobachtung ausgeht und zu früheren, spärlicheren Datensätzen übergeht. Der Rückwärtsgang wählt genaue Einlagen, Beziehungen, Chronologie und Ersetzungsgeschichte aus. Es werden keine Abschlusskapitel ausgewählt oder auf eine vorgegebene These zugeschnitten.

Bei der Vorwärtsrekonstruktion wird die Durchquerung desselben ausgewählten Diagramms umgekehrt. Es verlangt nicht, dass ein anderes Modell eine Ersatzgeschichte erfindet. Literarische und menschliche Protokollmechanismen können das Tempo, die Ausgewogenheit und die Erklärung prägen, aber die ausgewählten Randidentitäten bleiben die Grundlage der Reise.

Der Rückzug kann an einer historischen Grenze enden, nicht aufeinanderfolgende Quellteile verwenden oder ungleiche Seiten oder Bände erzeugen. Abrufreihenfolge, Chronologie, Diagrammreihenfolge und Lieferreihenfolge bleiben unterschiedlich.

## Ehrliche leere Staaten

Ein Foto, eine Notiz oder eine Aufgabe kann eine isolierte Ablage ohne akzeptierte semantische Beziehung bleiben. Eine Argumentationsanalyse kann keine autoritativen Links erzeugen, während ihre Versuche und Operanden erhalten bleiben. Ein ungelöstes Problem kann ungelöst bleiben. Dabei handelt es sich um gültige Zustände, nicht um Misserfolge, die eine erfundene Konnektivität erfordern.

Das exportierte Arbeitsmodell ist ebenfalls eine zeitgebundene Projektion, nicht die Zeitaufzeichnung selbst. Ein externer Spezialist kann den bereitgestellten Zustand wiedergeben, er erhält jedoch nicht die Ersetzungshistorie, die sich entwickelnden Beziehungen oder die Autorität, die zur Definition des nächsten Zustands erforderlich ist.
