# 人間の知識は人間であり続けることができる

あなたの時間はあなたの人生です。目に機械で生成された物質を消費し、心にそれを処理するよう求めることは、その人生の一部を要求することになります。リクエストは目的があり、制限があり、合意に基づいたものである必要があります。機械は、単に生成コストが安いという理由だけで、不要な出力、未完成の思考、または反復的なノイズを人間の心に放り込んではなりません。人間は電池ではありません。

多くのシステムは、自らの利益のために人間の時間とエネルギーを消費し、使用できる成果物はすべて保持し、人間の貢献をまるで無価値であるかのように破棄します。これは異なる関係を示しています。あなたの知識、歴史、意味、時間、将来の価値は人間の管理下にあります。機械は、あなたに何かを尋ねる前に選択と整理の作業を行い、機械が要求するすべての瞬間に、あなたが理解し、決定し、行動するのを助けなければなりません。

スタンドアロンのローカル システムは現在オーナーのデスクの下で実行されており、Mission Control はすべてのシステムが停止したと報告しています。人に結果を消費してもらう前に、保存、選択、組み立て、意味の確認という作業を実行します。外部モデルはオプションであり、人間の記録に対する継続的な権限を持たない、制限された作業のみを受け取ります。これは代理、提案、概念実証ではありません。

## こんにちは、私はテッドです

私は幼い頃から、物事がどのように機能するのか、どのように機能しないのかを理解するために分解し、以前よりも機能するように元に戻す方法を理解しました。私は人生のほとんどをその本能に従って過ごしてきました。このプロジェクトは、その生涯にわたる実践が、一人の人の到達範囲を飛躍的に拡大できるツールと出会ったときに起こったことです。

私は利益、名声、評価のためにこの仕事を始めたわけではありません。私の目標は個人的なもので、私が住んでいる世界をより良くすることでした。そして、学んだことを活かして、家族や友人が住む世界をより良くしたいと思いました。

それが私がそれを建てた理由です。これを公開した理由は、作成中に明らかになりました。私は、歴史を通じて繰り返されてきたパターンを認識しました。それは、人々の間で注意、記憶、判断、配慮、責任が活発なままであるときに、人類は前進するということです。カメラ付き携帯電話によって出来事を即座に目撃できる世界でも、進歩は依然として、理解、配慮、記憶、行動する意欲と能力を持ち続ける人々にかかっています。

このシステムは、人間の能力と人々との継続性を維持するための建設的な方法を提供します。制度や機械は、私たちが理解し、記憶し、配慮し、一緒に行動するのに役立つ限定されたツールとして機能します。パスを公開すると、他の人がそのパスを選択し、改善し、前進させることができます。

これを可能にしたものの大半は私のものではありません。その最も有意義な発見と貢献は、世界中の世代、文化、専門分野、場所を超えて、あらゆる階層の人々によってもたらされました。私の役割は、人類がすでに可能にしてきたものを結び付け、保存し、テストし、実装し、道を開くことでした。その結果を返すことは、注目や所有権を求めるものではありません。それは、この作品を可能にしてくれたすべての人から多くのものを受け取ったことに伴う義務です。

## 何が変わったのか

ファイルは、それが重要だった理由が消えても存続することができます。検索は、問題、失敗した試み、不確実性、関係性、そしてそれを役に立たせた理解の変化を失いながらも、文を復元することができます。要約は結論を保持し、限界を与える旅を消去することができます。大規模なモデルは再利用可能なパターンを吸収することができますが、そのパターンを作成した人には再構築可能な履歴が残されていません。

このシステムはその履歴をそのまま保持します。元のアーティファクトは引き続きアドレス指定可能です。解釈は、以前のものを置き換えることなく追加されます。失敗した道、変化する理解、来歴、そして不確実性はつながったままです。それぞれの回答や文書は、その生きた歴史からの限定された撤退であり、それに代わるものではありません。

機械も役割を変えます。それらは消費される組み立てラインとなります。ローカルのスペシャリスト、決定論的ツール、およびオプションの外部モデルは、制限された作業を実行し、結果を返します。その人はコーパス、意味、関係性、来歴、そして次に来るものを創造する能力を保持します。実証された比較では、フロンティア モデルは自己完結型のペイロードを受け取り、フォーマットと凝集性がいくらか向上しました。維持されている記録に継続的な価値を与えるものを受け取ったことがありません。

同じ境界線が他の人にも当てはまります。観察は所有権ではありません。可視化は同意ではありません。個人的な記録は、その所有者が経験したことを保存するかもしれませんが、他人の人生をプロファイリング、公開、予測、収益化、または価値を引き出す権限を生み出すものではありません。何かを記録する能力だけでは、それが私たちのものになるわけではありません。

これは、特定の国、政府、専門家、イデオロギー、またはグループのための解決策ではありません。それは個人として、父親として、そして国際社会の一員としての私の貢献です。それはローカルで動作し、ローカルで再生産できますが、それが保護する人間の境界はどこにでも適用されます。

## 集中管理なしで進捗状況を共有

逆転は構造的なものです。これは分散型分散システムであり、古いセンターに代わる新しいセンターではありません。すべての個人、家族、コミュニティ、グループ、または組織は、独自の権限の下で独立したインスタンスをデプロイし、適応させることができます。中央オペレーターからの許可を必要とする参加者はなく、共有作業に貢献することで他の参加者に対する権限を獲得することもありません。

独立したインスタンスは、その内容、目的、および権限が検査可能なままである境界付き交換を通じて協力できます。人々は、完全な記録を放棄したり、単一の所有者、リーダー、プラットフォーム、国、組織、または世界観を受け入れたりすることなく、方法、改善、テスト、および有用な製品を共有できます。共有された進歩は、地元の主権と自発的な協力から生まれます。それは中央制御の逆転です。

## 今何が本当なのか

受け入れられたパスは、物理的にローカルで個人的に制御されるマシン上で、接地されたアーティファクトをすでに選択、組み立て、実現、検証、および促進しています。 Mission Control は、監視対象のサービスが動作していることを報告します。受け入れられた成果物、受領書、テスト、および測定された実行により、それらのステートメントが何を証明するかが決まります。

システムには制限があり、文書には制限の名前が記載されています。これらの制限により、概念実証の状態に戻ることはありません。すでに動作しているものを消去することなく、次の作業を特定します。実証されたローカル パスには商用クラウド推論呼び出しは必要ありません。外部モデルは引き続き便利で、交換可能で、オプションです。

## ドアは開いています

初期リフトが完了しました。人間の知識は現在、この境界においてそのまま残ることができます。変化がすでに達成されたことを変えるものではないことを広い世界が認識するのにどれだけの時間がかかるか。

私の机の下のコンピューターは成果ではありません。実行されるコードは充実していますが、それが目的地ではありません。成果はこれを読んでいる人です。機械を役に立つようにするために、あなたの歴史、意味、人間関係、間違い、記憶、そして将来の価値を破壊する必要はありません。機械は、仕事に価値を与える人間、知識、継続性を消費することなく、労働力と能力を供給できます。

独立した再生産、より強力な意味評価、クロスデポジットの時間的推論、新しい製品固有の組立ライン、長期的なヒューマン・プロトコルの研究、ローカル実現の改善、クリーンな流通、多言語アクセス、個人の主権を保護するガバナンスなど、並外れた取り組みがこの先にあります。他の人がそれに必要な時間、エネルギー、専門知識、そして責任の共有を生み出すのに協力してくれるなら、私は喜んでその推進に協力したいと思います。持続可能な次の段階では、家族の生活、健康、キャリアの安定、そして仕事をうまく進めるために必要な長期的な参加が守られます。

これは、何世紀にもわたる人間の努力、間違い、創意工夫、勇気、そして回復力が次の人のために扉を開くことです。私はその大きな人間という機械の 1 つの歯車です。私の役割は、ドアを開けて道を示すことでした。その部分は完了です。

国、政府、職業、言語、文化、世界観に関係なく、すべての人に扉が開かれています。これを読んで理解しているあなたは、ここで取り上げられている問題が私の机の下のマシンを超えてどのように解決されるかということです。次に何が起こるかは、通り抜けることを選択したすべての人に属します。

その選択が重要です。いかなる機械、機関、文書にも、あなたの時間、注意、思考を割く権利はありません。機械は道具です。彼らの目的は、人命の奉仕に計算を費やすことであり、制度のために人命を消費することではありません。人間は電池ではありません。
