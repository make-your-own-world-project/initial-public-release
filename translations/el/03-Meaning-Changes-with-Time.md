# Σημασία Αλλαγές με το Χρόνο

![Προηγούμενα στοιχεία, μεταγενέστερο νόημα και μεταβαλλόμενες ερμηνείες παραμένουν συνδεδεμένα με την πάροδο του χρόνου](../../assets/temporal-meaning-preserved-history.png)

## Ο χάρτης βρίσκεται πάνω από το σώμα

Το σώμα διατηρεί καταθέσεις. Ένα ξεχωριστό χρονικό επίπεδο καταγράφει σχέσεις, ερμηνείες, προσπάθειες ταξινόμησης, συνεισφορές σπουδαιότητας και την ιστορία τους. Αυτό το επίπεδο μπορεί να αλλάζει συνεχώς χωρίς να αλλάζει τα αρχικά τεχνουργήματα.

Ένας προηγούμενος σύνδεσμος δεν διαγράφεται όταν είναι καλύτερη μια μεταγενέστερη ερμηνεία. Η μεταγενέστερη παρατήρηση μπορεί να την επιβεβαιώσει, να την περιορίσει, να την αντιφάσκει, να την επαναταξινομήσει ή να την αντικαταστήσει. Ο προηγούμενος σύνδεσμος παραμένει έγκυρος ως η προβολή που ήταν διαθέσιμη σε αυτήν την κατάσταση και μπορεί να εξηγήσει τη διαδρομή για μεταγενέστερη εργασία.

## Ο χρόνος δεν είναι μία χρονική σήμανση

Το σύστημα διακρίνει τουλάχιστον:

- όταν ένα τεχνούργημα παρατηρήθηκε από το σώμα?
- όταν καταγράφηκε ή δημιουργήθηκε μια συγκεκριμένη αναπαράσταση·
- όταν η δραστηριότητα στον πραγματικό κόσμο μπορεί να έχει ξεκινήσει·
- όταν ένα συμβάν φαίνεται να έχει συμβεί·
- αν το τεχνούργημα αναφέρεται σε παρελθόν, παρόν, μέλλον, μικτό, διαχρονικό ή άγνωστο
  φορά;
- όταν μια ερμηνεία θεωρήθηκε έγκυρη·
- πότε καταγράφηκε αυτή η ερμηνεία·
- όταν μια μεταγενέστερη παρατήρηση το αντικατέστησε.

Ένα έγγραφο που έγινε δεκτό πρόσφατα μπορεί να αφορά εργασίες που έχουν ξεκινήσει πολύ νωρίτερα. Μια παρούσα σημείωση μπορεί να είναι ανάμνηση, πρόβλεψη, ανησυχία, προγραμματισμός ή ένας διαχρονικός προβληματισμός. Η είσοδος δεν αντιμετωπίζεται ποτέ ως απόδειξη έναρξης.

## Οι λόγοι είναι παρατηρήσεις, όχι μόνιμες ετικέτες

Μια σχέση που μοιάζει με λογική καταγράφει την εξουσία και τη γνωσιολογική της θέση. Μπορεί να είναι μια δήλωση άμεσης πηγής, δομή που παρατηρείται άμεσα, υποψήφιος προερχόμενος από ειδικό, ντετερμινιστική προβολή, υποστηριζόμενο συμπέρασμα, πιθανή συσχέτιση, αντίφαση, εκ νέου απόδοση ή άγνωστη.

Η δομική προβολή, η εμπιστοσύνη του μοντέλου, η επανάληψη, η κεντρική θέση και η προσαρμογή του κοινού μπορεί να είναι χρήσιμες διαστάσεις. Κανένα δεν μετατρέπεται σιωπηλά σε αυτό που νοιαζόταν ένα άτομο.

## The Personal Meaning Matrix

Ο Πίνακας Προσωπικών Νοημάτων είναι μια προβολή εύρους αιτήματος για αυτές τις παρατηρήσεις που συνδέονται με την πηγή. Μπορεί να κρατήσει πολλές διαστάσεις χωρίς να τις εξαναγκάσει σε έναν αριθμό καθολικής σημασίας. Οι διαστάσεις των υποψηφίων περιλαμβάνουν:

- επένδυση προσοχής και προσπάθειας·
- δομή έργου και δραστηριότητας·
- εξέχουσα θέση του λόγου και αιτιώδης προσέγγιση·
- ισχύς και αβεβαιότητα αποδεικτικών στοιχείων.
- προστασία από συγκρούσεις, διόρθωση και ανοιχτές ερωτήσεις.
- εξωτερικούς περιορισμούς και περιβαλλοντικές συνθήκες·
- αξίες, ταυτότητα, αξιολόγηση και επιδιωκόμενα αποτελέσματα όταν αποδεικνύονται·
- εκφραστικός τρόπος, προβληματισμός, χιούμορ, ειρωνεία ή καλλιτεχνικό καδράρισμα.
- επιμονή και αλλαγή με την πάροδο του χρόνου.
- συνάφεια με έναν δηλωμένο δέκτη και προϊόν.

Το matrix δεν είναι προσομοιωτής προσωπικότητας και δεν απαντά σε μια διαχρονική ερώτηση για το τι θα έλεγε κάποιος. Η κατάσταση του παρατηρητή είναι χρονικά περιορισμένη. Μια μεταγενέστερη κατάσταση μπορεί να διαφέρει από μια προηγούμενη, και οι δύο παραμένουν μέρος του χάρτη.

## Ανακάλυψη προς τα πίσω και μπροστινή ανασυγκρότηση

Τα αυθαίρετα δεδομένα γίνονται συχνά πιο κατανοητά όταν η διέλευση ξεκινά από μια μεταγενέστερη παρατήρηση πλούσια σε περιβάλλον και κινείται προς παλαιότερες, πιο αραιές εγγραφές. Η αντίστροφη διαδρομή επιλέγει ακριβείς καταθέσεις, σχέσεις, χρονολογία και ιστορικό αντικατάστασης. Δεν επιλέγει τελικά κεφάλαια ούτε κλαδεύει προς μια προκαθορισμένη διατριβή.

Η ανακατασκευή προς τα εμπρός αντιστρέφει τη διέλευση στο ίδιο επιλεγμένο γράφημα. Δεν ζητά από άλλο μοντέλο να εφεύρει μια υποκατάστατη ιστορία. Οι μηχανισμοί του λογοτεχνικού και του ανθρώπινου πρωτοκόλλου μπορεί να διαμορφώνουν τον ρυθμό, την ισορροπία και την εξήγηση, αλλά οι επιλεγμένες ταυτότητες των άκρων παραμένουν η βάση του ταξιδιού.

Η απόσυρση μπορεί να σταματήσει σε ένα ιστορικό όριο, να χρησιμοποιήσει μη διαδοχικά εξαρτήματα πηγής ή να δημιουργήσει άνισες σελίδες ή τόμους. Η σειρά ανάκτησης, η χρονολογία, η σειρά γραφημάτων και η σειρά παράδοσης παραμένουν διακριτές.

## Ειλικρινείς κενές πολιτείες

Μια φωτογραφία, μια σημείωση ή μια εργασία μπορεί να παραμείνει μια απομονωμένη κατάθεση χωρίς αποδεκτή σημασιολογική σχέση. Μια συλλογιστική ανάλυση μπορεί να παράγει μηδενικούς έγκυρους συνδέσμους διατηρώντας τις προσπάθειες και τους τελεστές της. Ένα άλυτο πρόβλημα μπορεί να παραμείνει άλυτο. Αυτές είναι έγκυρες καταστάσεις, όχι αποτυχίες που απαιτούν κατασκευασμένη συνδετική πεζογραφία.

Το εξαγόμενο μοντέλο εργασίας είναι επίσης μια χρονικά περιορισμένη προβολή, όχι η ίδια η χρονική εγγραφή. Ένας εξωτερικός ειδικός μπορεί να αποδώσει την παρεχόμενη κατάσταση, αλλά δεν αποκτά το ιστορικό αντικατάστασης, τις εξελισσόμενες σχέσεις ή την εξουσία που απαιτείται για να ορίσει την επόμενη κατάσταση.
