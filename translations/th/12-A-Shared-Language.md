# ภาษาที่ใช้ร่วมกัน

![แนวคิดที่เกิดขึ้นซ้ำๆ ของสถาปัตยกรรมที่จัดเรียงอยู่ในคลังข้อมูลท้องถิ่นที่ไม่เสียหายเพียงแห่งเดียว](../../assets/architecture-glossary.png)

**สิ่งประดิษฐ์**: อินพุตที่เก็บรักษาไว้หรือผลิตภัณฑ์ที่สร้างขึ้น

**เงินฝาก**: สิ่งประดิษฐ์ที่เข้าสู่คลังข้อมูลที่เชื่อถือได้ การดำรงอยู่ของมันมีคุณค่าแม้ว่าจะยังไม่ทราบเหตุผลหรือความสัมพันธ์ก็ตาม

**การถอนออก**: การเรียกคืนหรือสร้างผลิตภัณฑ์แบบมีขอบเขตซึ่งทำจากเงินฝากที่เลือกและการสังเกตที่ได้รับ มันไม่เคยแทนที่แหล่งที่มาของมัน

**การเป็นตัวแทน**: มุมมองที่ได้รับ เช่น ข้อความที่แยกออกมา คำอธิบายสื่อ การฝัง หน่วยความหมาย หรือการจำแนกประเภท

**เหตุการณ์สังเกตการณ์**: หลักฐานที่แสดงว่าเกิดมุมมอง ปฏิกิริยา คำถาม หรือรายงาน มันแตกต่างจากความจริงของข้อเสนอใดๆ ที่อยู่ข้างใน

**บทบาทเชิงนามธรรม**: สถานะของเนื้อหาเป็นการสังเกต การกล่าวอ้าง การตีความ สมมติฐาน อุปมา ความรู้สึก คำถาม แผนงาน ความล้มเหลว การแก้ไข การอ้างอิง หรือไม่ทราบ

**แผนที่ชั่วคราว**: เลเยอร์ความสัมพันธ์ที่มีเวอร์ชันอยู่เหนือคลังข้อมูล รวมถึงประวัติการสังเกต ความถูกต้อง และประวัติเซสชัน

**เมทริกซ์ความหมายส่วนบุคคล**: การฉายภาพหลายมิติตามขอบเขตคำขอของการมีส่วนร่วมและความไม่แน่นอนที่มีนัยสำคัญที่เชื่อมโยงกับแหล่งที่มา มันไม่ใช่แบบอย่างบุคลิกภาพ

**เดินถอยหลัง**: การข้ามจากเป้าหมายที่มีบริบทมากมายไปยังหลักฐานที่เกี่ยวข้องก่อนหน้านี้ โดยไม่ต้องกำหนดโครงสร้างผลิตภัณฑ์ขั้นสุดท้าย

**การสร้างใหม่ล่วงหน้า**: การกลับรายการกราฟที่เลือกไว้เดียวกันเพื่ออธิบายการเดินทางตามลำดับที่มนุษย์สามารถถอดรหัสได้

**ยุบ**: เฉพาะผลิตภัณฑ์ การแบ่งพาร์ติชันกราฟที่เลือกโดยสูญเสียไปอย่างชัดเจนกับงานเชิงความหมายและวาทศิลป์

**ฟันเฟืองหรือผู้เชี่ยวชาญ**: ส่วนประกอบที่มีขอบเขตพร้อมอินพุต เอาท์พุต ขีดจำกัด ต้นทุน และสิทธิ์ที่ประกาศไว้

**สายการประกอบ**: การจัดการเฉพาะผลิตภัณฑ์ของผู้เชี่ยวชาญที่ใช้ในการสร้างการถอนเงิน

**แฮนด์ออฟ**: เพย์โหลดที่พิมพ์และการโอนความรับผิดชอบระหว่างผู้เชี่ยวชาญ

**รูปแบบการทำงานขนาดกะทัดรัด**: หลักฐานแบบพกพา เหตุผล ข้อกำหนดของผลิตภัณฑ์ และด้ามจับขยายที่ประกอบขึ้นเป็นเอาต์พุตเดียว ไม่ใช่โมเดลทั่วไปที่ได้รับการฝึกอบรม

**บัญชีแยกประเภทเพย์โหลด**: บันทึกการตรวจสอบสิ่งที่แต่ละขั้นตอนได้รับ ผลิต ละเว้น ต้นทุน และมีส่วนร่วม

**พิธีสารของมนุษย์**: ขอบเขตสองทิศทางสำหรับการปรับโครงสร้างเครื่องให้เข้ากับสถานะการสื่อสารของมนุษย์โดยเฉพาะ โดยไม่อ้างสิทธิ์ในการเข้าถึงการใช้งานภายในของบุคคล

**สาน**: วิถีที่วัดได้และความสมดุลของฟังก์ชันการนำส่งทั่วทั้งผลิตภัณฑ์

**ความแน่น**: สเกลหรือพารามิเตอร์ความหนาแน่นที่ใช้กับลายทอโดยไม่ต้องกำหนดงานส่งมอบใหม่

**การต่อสายดิน**: ข้อกำหนดที่ว่าการบริจาคที่สร้างขึ้นยังคงตรวจสอบย้อนกลับไปยังหลักฐานที่ได้รับอนุญาต หรือพิมพ์อย่างชัดเจนว่าเป็นการตีความ ความไม่แน่นอน หรือการขาดหายไป

**ประตูรับ**: การตรวจสอบอิสระที่จำเป็นต้องมีค่าคงที่สำหรับไบต์ของสิ่งประดิษฐ์ที่แน่นอน การออกจากกระบวนการเพียงอย่างเดียวไม่ถือเป็นการยอมรับ

**การแทนที่**: การสังเกตในภายหลังแทนที่การตีความก่อนหน้านี้เพื่อใช้ในภายหลังโดยไม่ต้องลบสถานะทางประวัติศาสตร์ก่อนหน้า

**อำนาจอธิปไตยส่วนบุคคล**: ความเป็นเจ้าของและขอบเขตอำนาจรอบประสบการณ์ ตัวตน ความสนใจ การแสดงออก และความสามารถในการกำหนดความหมายของบุคคล

**การสนับสนุนภายนอกที่มีขอบเขตจำกัด**: แฮนด์ออฟเฉพาะคำขอที่ได้รับอนุญาต ซึ่งผู้เชี่ยวชาญภายนอกจะได้รับเฉพาะเพย์โหลดที่จำเป็นสำหรับการดำเนินการที่ประกาศครั้งเดียวเท่านั้น เพย์โหลดอาจมีประโยชน์ในขณะที่ยังคงไม่เพียงพอที่จะสร้างคลังข้อมูลที่ได้รับการบำรุงรักษา ที่มา ประวัติศาสตร์ชั่วคราว ความหมายส่วนบุคคล หรือกลไกที่ทำให้เกิดการถอนออกในอนาคต ขอบเขตนี้ป้องกันไม่ให้การมีส่วนร่วมแคบๆ กลายเป็นการสกัดและการลดทอนความรู้ของมนุษย์ไปสู่คุณค่าทางสถาบัน
