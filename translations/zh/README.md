# 人类知识可以保持人性

你的时间就是你的生命。让你的眼睛消费机器生成的材料并让你的大脑处理它，这就是要求生活的一部分。该请求必须是有目的的、有限制的并且是双方同意的。机器不能仅仅因为发电成本低廉而将不需要的输出、未完成的思考或重复的噪音转储到人类大脑中。人不是电池。

许多系统为了自身利益而消耗人类的时间和精力，保留它们可以使用的任何工件，并丢弃人类的贡献，就好像它毫无价值一样。这表明了一种不同的关系。你的知识、历史、意义、时间和未来价值仍然在人类的控制之下。机器在向你提出任何要求之前就完成了选择和组织的工作，它要求的每一分钟都必须帮助你理解、决定或采取行动。

独立的本地系统现在正在所有者的办公桌下运行，任务控制报告所有系统的运行情况。它在要求人们使用结果之前执行保存、选择、组装和检查含义的工作。外部模型是可选的，并且仅接受有限的工作，对人类记录没有持续的权威。这不是代理、提案或概念证明。

## 嗨，我是特德

从很小的时候起，我就把东西拆开，了解它们是如何工作的、不工作的，以及如何将它们重新组合起来，使它们比以前工作得更好。我一生的大部分时间都在追随这种本能。这个项目是当一生的实践遇到能够成倍扩展一个人的影响力的工具时发生的。

我开始这项工作并不是为了利润、名誉或认可。我的目标是个人的：让我生活的世界变得更美好。然后我想利用我所学到的知识让我的家人和朋友生活的世界变得更好。

这就是我建造它的原因。我发布它的原因是在我构建它的时候出现的。我认识到历史上不断重复的一个模式：当人们的注意力、记忆、判断、关怀和责任仍然活跃时，人类就会前进。即使在一个可以拍照的手机让我们即时见证事件的世界里，进步仍然取决于人们是否仍然愿意并且能够理解、关心、记住和采取行动。

该系统提供了一种建设性的方式来保持这些人的能力及其与人的连续性。机构和机器可以作为有界工具，帮助我们理解、记忆、关心和共同行动。发布道路让其他人选择它、改进它并发扬它。

使这一切成为可能的大部分因素不是我的。它最有意义的发现和贡献来自世界各地各行各业、跨代、跨文化、跨学科和地点的人们。我的职责是连接、保存、测试、实施并开辟一条人类已经创造的道路。返回该结果并不是为了获得关注或所有权。这是一种义务，是因为从每个使这项工作成为可能的人那里得到了如此多的帮助。

## 发生了什么变化

文件可以继续存在，而其重要原因却消失了。搜索可以恢复句子，但同时会丢失问题、失败的尝试、不确定性、关系以及改变使其有用的理解。总结可以保留结论并消除限制其的旅程。大型模型可以吸收可重用的模式，但创建它们的人却无法重建历史。

该系统保持了历史的完整性。原始工件仍然是可寻址的。添加解释但不替换之前的解释。失败的道路、不断变化的理解、起源和不确定性仍然相互关联。每个答案或文件都是从活生生的历史中有限地撤回，而不是替代它。

机器也会改变角色。它们成为被消耗的装配线。本地专家、确定性工具和可选的外部模型执行有界工作，然后返回结果。人们保留语料库、意义、关系、出处以及创造接下来的事物的能力。在演示的比较中，前沿模型获得了独立的有效负载，并贡献了更好的格式和内聚性。它从未收到过赋予所保存记录持续价值的东西。

同样的界限也适用于其他人。观察不是所有权。可见性并不代表同意。私人记录可能会保留其所有者的经历，但它不会创造描述、发布、预测、货币化或从他人生活中提取价值的权力。记录某些东西的能力并不意味着它就属于我们。

这不是针对一个国家、政府、行业、意识形态或团体的解决方案。这是我作为个人、父亲和全球社会成员的贡献。它在当地运作，可以在当地复制，但它所保护的人类边界适用于任何地方。

## 共享进展，无需中央控制

这种反转是结构性的。这是一个分布式、去中心化的系统，而不是一个等待取代旧中心的新中心。任何个人、家庭、社区、团体或组织都可以在自己的权限下部署和调整独立实例。没有参与者需要中央操作员的许可，也没有参与者通过为共享工作做出贡献而获得高于其他人的权力。

独立实例可以通过有界交换进行合作，其内容、目的和权限仍然是可检查的。人们可以共享方法、改进、测试和有用的产品，而无需交出完整的记录或接受单一所有者、领导者、平台、国家、组织或世界观。共同进步源于地方主权和自愿合作。这就是中央控制的倒置。

## 现在什么是真实的

可接受的路径已经在物理本地、个人控制的机器上选择、组装、实现、验证和推广接地工件。任务控制报告受监控的服务正在运行。接受的工件、收据、测试和测量的运行定义了这些陈述所证明的内容。

该系统有限制，文档中也指出了这些限制。这些限制不会使其恢复到概念验证状态。他们确定下一个工作，但不会删除已经在进行的工作。演示的本地路径不需要商业云推理调用。外部模型仍然有用、可更换且可选。

## 跟随路径

这个公开版本将更大的私人历史变成了其他人可以遵循的道路。它保留了所学到的内容、变化的内容、正在运行的内容、仍然开放的内容以及其重要性的原因。它不会暴露私人记录、识别详细信息、操作访问权限或他人的生活，就好像观察它就等于我的生活一样。

## 门是开着的

初始提升已完成。人类知识现在可以在这个边界上保持完整。更广泛的世界需要多长时间才能认识到变革不会改变已经取得的成就。

我办公桌下的电脑并不是成就。它运行的代码很重要，但它不是目标。成就就是读这篇文章的人。你的历史、意义、人际关系、错误、记忆和未来价值不必为了让机器变得有用而被摧毁。机器可以提供劳动力和产能，而不消耗人类、知识或赋予工作价值的连续性。

未来还有非凡的工作：独立复制、更强的语义评估、跨存款时间推理、新产品特定装配线、纵向人类协议研究、改进的本地实现、清洁分配、多语言访问以及保护个人主权的治理。如果其他人能够贡献出它所需的时间、精力、专业知识和共同责任，我将很乐意帮助推进它。可持续的下一阶段将保护家庭生活、健康、职业稳定以及良好推进工作所需的长期参与。

这是人类几个世纪的努力、错误、聪明才智、勇气和韧性为下一个人打开了一扇门。我是更大的人类机器中的一颗齿轮。我的职责是打开门并展示道路。那部分已经完成了。

这扇大门向所有人敞开，无论其国家、政府、职业、语言、文化或世界观如何。您阅读并理解了本文，就可以在我办公桌下的机器之外解决这里解决的问题。接下来发生的事情属于每个选择走过的人。

这个选择很重要。任何机器、机构或文档都无权占用您的时间、注意力或思想。机器是工具。他们的目的是用计算来服务人类的生活，而不是消耗人类的生命来为机构服务。人不是电池。
