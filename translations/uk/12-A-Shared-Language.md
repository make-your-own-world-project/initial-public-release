# Спільна мова

![Повторювані концепції архітектури, розташовані навколо одного незайманого місцевого архіву](../../assets/architecture-glossary.png)

**Артефакт**: будь-який збережений вхідний або створений продукт.

**Депозит**: артефакт, що входить до авторитетного корпусу. Його існування має цінність, навіть якщо причина чи зв’язок ще невідомі.

**Вилучення**: обмежене отримання або згенерований продукт, створений на основі вибраних депозитів і похідних спостережень. Він ніколи не замінює своїх джерел.

**Подання**: похідний вигляд, як-от витягнутий текст, медіа-опис, вбудовування, семантична одиниця або класифікація.

**Подія спостереження**: доказ того, що відбулася точка зору, реакція, запитання чи повідомлення. Воно відрізняється від істинності будь-якої пропозиції в ньому.

**Епістемічна роль**: статус вмісту як спостереження, твердження, інтерпретація, гіпотеза, метафора, відчуття, запитання, план, невдача, виправлення, цитата або невідоме.

**Тимчасова карта**: рівень зв’язків із версіями над корпусом, включаючи спостереження, валідність і історію заміни.

**Матриця особистих значень**: багатовимірна проекція значущих вкладів і невизначеностей, пов’язаних із джерелом. Це не модель особистості.

**Назад**: перехід від контекстної цілі до попередніх пов’язаних свідчень без призначення кінцевої структури продукту.

**Перехідна реконструкція**: реверс над тим самим вибраним графіком, щоб пояснити подорож у порядку, який може декодувати людина.

**Згортання**: специфічне для продукту розділення вибраних гілок графа з явними втратами семантичних і риторичних завдань.

**Cog або спеціаліст**: обмежений компонент із заявленими входами, виходами, обмеженнями, вартістю та повноваженнями.

**Складальна лінія**: спеціальна структура спеціалістів для створення вилучення.

**Handoff**: введене корисне навантаження та передача відповідальності між спеціалістами.

**Компактна робоча модель**: портативні докази, міркування, вимоги до продукту та ручки розширення, зібрані для одного виходу. Це не навчена загальна модель.

**Реєстрація корисного навантаження**: аудиторський запис того, що кожен етап отримав, створив, пропустив, витратив і вніс.

**Протокол людини**: двонаправлена ​​межа для адаптації машинної структури до конкретного стану спілкування людини без вимоги доступу до внутрішньої реалізації людини.

**Плетіння**: виміряна траєкторія та баланс функцій доставки в продукті.

**Щільність**: параметр масштабу або щільності, застосований до переплетення без перевизначення завдань доставки.

**Обґрунтування**: вимога, щоб створений внесок залишався простежуваним до авторизованих доказів або був чітко надрукований як інтерпретація, невизначеність або відсутність.

**Шлюз отримання**: незалежна перевірка, яка вимагає збереження інваріантів для точних байтів артефакту. Сам по собі вихід із процесу не є прийняттям.

**Суперсесія**: пізніші спостереження, що замінюють попередню інтерпретацію для подальшого використання без видалення попереднього історичного стану.

**Особистий суверенітет**: межа власності та влади навколо досвіду, ідентичності, уваги, самовираження та здатності визначати значення людини.

**Обмежений зовнішній внесок**: авторизована передача обслуговування, що залежить від запиту, у якій сторонній спеціаліст отримує лише корисне навантаження, необхідне для однієї заявленої операції. Корисне навантаження може бути корисним, але залишатися недостатнім для реконструкції підтримуваного корпусу, походження, тимчасової історії, особистого значення або механізму, який створює майбутні вилучення. Ця межа запобігає тому, щоб вузький внесок перетворився на вилучення та деструктивне зведення людських знань до інституційної цінності.
